🚨 Mandatory Driver Coding & Operational Standards

1. Morning Organization & Eliminating Code 27: Organize every shelf before leaving the station and catch misloads/bad addresses at the dock so you never skip a stop and find the package at the end of the day.

2. Accuracy Over Speed: Obey all posted speed limits on highways and streets, wear your seatbelt 100% of the time, and read every shipping label twice before leaving the package.

3. Strict Pickup Windows & 100% Scanning: Pick up packages strictly within the designated window—never early and never late—and scan every single package as you load it into the truck.

4. Exception Codes (Code 02, Code 27 & Code 85):

  • Code 04: Business closed during normal hours.
  • Code 07: Residential access blocked or signature required with no one home (leave door tag).
  • Code 11: Business closed on weekends.
  • Code 02 (Incorrect Address ONLY): Never use Code 02 because you "cannot find" a place. Call Station Management / Dispatch from the stop first.
  • No Code 85 Inside the Truck: Every undelivered package left behind in the truck must be properly coded before returning to the terminal.

5. End-of-Day Truck Cleanliness (Zero Tolerance): Clean all trash from the cab and cargo area daily. Zero tolerance for urine ("pee") bottles inside the trucks.
